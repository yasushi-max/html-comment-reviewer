# HTMLコメントレビューア の使い方

HTMLで作った資料に、**Wordのコメント機能のように修正指示を付けて、Claudeに修正してもらう**ためのツールです。
本体は [HTMLコメントレビューア.html](HTMLコメントレビューア.html) の1ファイルだけで、ダブルクリックすればブラウザで開きます（インターネット接続・インストール不要）。

## 基本の流れ

1. **開く** — `HTMLコメントレビューア.html` をダブルクリックして開き、レビューしたい資料（HTMLファイル）を画面にドラッグ＆ドロップ（または「📂 HTMLを開く」）
2. **コメントか直接修正を付ける** — 直したい文字をマウスで選択すると、2つのボタンが出ます
   - **💬 コメント** …「こう直して」という指示を書く（Wordのコメントと同じ感覚）
   - **✏️ 直接修正** … 修正後の文言を自分で入力する。画面では元の文言に取り消し線、隣に新しい文言が緑色で表示されます（Wordの変更履歴と同じ見た目）。Claudeが反映時にその文言へそのまま置き換えます
   - 資料全体への指示（例：「全体的にトーンを柔らかく」）は右上の「＋ 全体コメント」
   - どれも後から「編集」「削除」できます。本文のハイライトとサイドバーは連動してジャンプします
3. **デザインを調整する（🎨 デザイン調整）** — 上部の「🎨 デザイン調整」ボタンを押すとモードが切り替わります
   - 調整したいブロックを**クリックで選択**（紫の枠と四隅のハンドルが出ます）。**ドラッグで移動**、**四隅のハンドルでサイズ変更**
   - ツールバーは3つのタブに分かれています：
     - **文字** — フォント選択（その資料で使われているフォント／游ゴシック・メイリオ・Meiryo UI等の定番／どのPCでも同じ表示になるWebフォント／名前の自由入力。一覧は実際のフォントの見た目で表示されます）、文字の大きさ（A＋/A−）、太字・斜体・下線・取消線、行間、字間、揃え（左/中央/右）
     - **色・枠** — 文字色・背景色・外枠（細/太・色・角丸）・影・透明度。色は**Word風のパレット**（その資料で使われている色を自動で並べます）か、**🎯スポイト**（画面上の色をそのまま採取）で選べます
     - **配置** — 並び順の入れ替え（↑前へ/↓後ろへ）、複製、削除、内側余白の調整
   - 「⬆ 親」でひとまわり外側のブロックを選択、「↺ 戻す」でその要素の調整を取り消し
   - 調整内容は「どの要素を・どう変えたか」という指示として記録され、Claudeが反映時に**数値の書き写しではなく、レイアウトを壊さない自然なCSSで本実装**します
   - もう一度ボタン（または上部の紫のバナー）を押すと通常のコメントモードに戻ります
4. **保存** — 「💾 コメント付きで保存」→ **`元の名前_コメント付き.html`** ができます（保存先を選ぶ画面が出た場合は選んだ場所に、出ない場合はダウンロードフォルダ）
5. **Claudeに渡す** — そのファイルをClaude Codeのチャットにドラッグして、ひとこと頼むだけ：

   > このファイルのコメントを反映して、修正版を作ってください

   コメントの内容とClaude向けの処理手順はファイルの中に自動で埋め込まれているので、これだけで伝わります。Claudeは修正後に `元の名前_修正版.html` を作り、元のファイルは残します。

## 続きから編集したいとき

保存した `◯◯_コメント付き.html` をもう一度このツールで開けば、コメントが復元され、追加・編集を続けられます。

## 対応環境

- **パソコンのブラウザ**で使ってください：Edge / Chrome / Safari / Firefox の最新版（Windows・Mac両対応）。スマホ・タブレットは非対応です
- ツールも資料も、**ファイルをパソコンに保存してから開いてください**。メール・Teams・Dropbox等の「プレビュー画面」で直接開くと、ブラウザの制限で動かないことがあります
- 資料のHTMLは構成を問わず使えます（スライド形式・レポート形式・見出しの有無など自由）。文字コードはUTF-8のほかShift_JIS・EUC-JPも自動判別します

## 注意点

- **保存した `◯◯_コメント付き.html` を普通にブラウザで開いても、コメントは画面に表示されません**（ファイル内部に埋め込まれているためです）。コメントを確認したいときは、このツールで開き直してください
- 資料が**真っ白だったり表示が崩れる**場合は、上部の「スクリプトを実行（表示が崩れる資料用）」にチェックを入れてください。グラフや動きのある資料で必要になることがあります（自分で作った資料以外でのオンは避けてください）
- 資料が画像を**相対パス**で参照している場合、ツール上では画像が表示されないことがあります（コメント機能・修正結果には影響ありません）
- 保存していないコメントがある状態で画面を閉じようとすると、確認が表示されます
